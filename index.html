Overview

Clinical notes are written for clinicians. This dataset pairs full report text with extracted findings and a baseline summary, so you can fine-tune or evaluate models that explain reports to patients.

Quick start

Unzip the archive, then load whichever format fits your pipeline.

import pandas as pd
from datasets import load_dataset

# Structured CSV
df = pd.read_csv("Medical_Reports_Simplification_Dataset.csv")
print(df.medical_specialty.value_counts().head())

# Instruction-tuning JSONL
ds = load_dataset("json", data_files="medical_reports_simplification.jsonl")["train"]
print(ds[0]["instruction"])

Before you train

Things to know about this data
  • The outputs are seeds, not finished simplifications. They are assembled from the overview and extracted findings, and often keep the original clinical wording. Plan to rewrite or review them before treating them as ground truth.
  • Many rows are duplicates. 1,984 records repeat another record’s report text, leaving 1,817 unique reports. Some reports appear under more than one specialty. Deduplicate and split by report text to avoid train/test leakage.
  • Record count differs from the README. The README says 3,813 CSV records, while the files contain 3,801.
  • Findings are sometimes missing. 1,148 rows have no extracted findings section.
  • Not for clinical use. Outputs from models trained on this data should be checked by a qualified professional before reaching patients.
